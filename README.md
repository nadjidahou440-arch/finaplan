# FinaPlan — موقع تعريفي ثنائي اللغة

موقع ثابت (Static Website) للتعريف بفكرة FinaPlan: منصة مقترحة لدعم التخطيط المالي للمؤسسات الصغيرة والمتوسطة في الجزائر.

## الملفات
- `index.html`: محتوى الموقع.
- `style.css`: التصميم المتجاوب.
- `script.js`: التبديل بين العربية والفرنسية وقائمة الهاتف.

## خصائص النسخة الحالية
- موقع تعريفي فقط، لا يحتاج إلى حسابات أو قاعدة بيانات.
- واجهة عربية وفرنسية.
- تصميم متجاوب للهاتف والحاسوب.
- أقسام للتعريف، والخدمات المقترحة، ومنهجية التخطيط، والفئة المستهدفة، والتواصل.
- الرسوم والأرقام المعروضة توضيحية وافتراضية.

## ما هو تجريبي؟
- FinaPlan في هذه النسخة مفهوم/علامة تجريبية وليس خدمة مالية عاملة.
- لوحة الميزانية في الصفحة الرئيسية صورة توضيحية ببيانات افتراضية.
- لا توجد أدوات مالية حقيقية أو حفظ بيانات أو تسجيل دخول.
- رابط البريد الإلكتروني في قسم التواصل يستخدم نطاقًا تجريبيًا `.example` ويجب استبداله ببريد حقيقي قبل النشر.

## النشر مجانًا باستخدام GitHub Pages
1. أنشئ مستودعًا جديدًا على GitHub.
2. ارفع الملفات الثلاثة إلى جذر المستودع.
3. افتح Settings ثم Pages.
4. اختر النشر من الفرع `main` والمجلد `/ (root)`.
5. احفظ الإعدادات وانتظر رابط GitHub Pages الذي سيظهر في صفحة Pages.

يمكن أيضًا نشر المجلد عبر Netlify أو Vercel. هذا المشروع لا يتطلب خادمًا خلفيًا.
